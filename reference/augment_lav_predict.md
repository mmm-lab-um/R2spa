# Obtain factor scores and related definition variables from a `lavaan` object for 2S-PA analyses.

The score columns are obtained by calling the
[`lavaan::lavPredict()`](https://rdrr.io/pkg/lavaan/man/lavPredict.html)
function; the per-row definitions of those scores (standard errors,
loading/cross-loading matrix, error variance-covariance matrix,
intercepts) come from the canonical
[`get_fs()`](https://mmm-lab-um.github.io/R2spa/reference/get_fs.md)
pattern blocks (the same
[`compute_fscore()`](https://mmm-lab-um.github.io/R2spa/reference/compute_fscore.md)
engine
[`get_fs()`](https://mmm-lab-um.github.io/R2spa/reference/get_fs.md)
itself uses), so there is one source of truth for `fsL`/`fsT`/SE shared
with
[`get_fs()`](https://mmm-lab-um.github.io/R2spa/reference/get_fs.md) and
[`fs_indiv()`](https://mmm-lab-um.github.io/R2spa/reference/fs_indiv.md).

## Usage

``` r
augment_lav_predict(
  lavobj,
  method = c("regression", "Bartlett"),
  drop_list_single = TRUE,
  ...
)
```

## Arguments

- lavobj:

  A fitted
  [`lavaan::lavaan`](https://rdrr.io/pkg/lavaan/man/lavaan-class.html)
  object

- method:

  A character string indicating the scoring method to use. Must be
  either `"regression"` or `"Bartlett"`. The score columns are taken
  from [`lavPredict`](https://rdrr.io/pkg/lavaan/man/lavPredict.html)()
  (which reproduces lavaan's `NA` convention for Bartlett factors with
  no observed indicator); this function intentionally does not support
  the `"mean"` (sum-score) method of
  [`get_fs()`](https://mmm-lab-um.github.io/R2spa/reference/get_fs.md).

- drop_list_single:

  logical. Should the results be unlisted for single-group models?

- ...:

  Additional arguments passed to
  [`lavaan::lavPredict()`](https://rdrr.io/pkg/lavaan/man/lavPredict.html)

## Value

A `data.frame` containing the factor scores, the corresponding standard
errors, the loadings and cross-loadings of the factor scores as
indicators of the latent variables, the error variance-covariance matrix
of the factor scores, and the measurement intercepts (legacy column
layout: `fs_*`, `fs_*_se`, `<indicator>_by_fs_*`, `ev_*`/`ecov_*` in
upper-triangular order, and `int_*`). The per-row values are identical
to those returned by `fs_indiv(get_fs(lavobj, method = method))`; the
standard-error columns share the canonical `fs_*_se` naming of
[`get_fs()`](https://mmm-lab-um.github.io/R2spa/reference/get_fs.md)/[`fs_indiv()`](https://mmm-lab-um.github.io/R2spa/reference/fs_indiv.md),
and the only difference from them is the ordering of the `ev_*`/`ecov_*`
columns (upper-triangular here, lower-triangular in
[`get_fs()`](https://mmm-lab-um.github.io/R2spa/reference/get_fs.md) and
[`fs_indiv()`](https://mmm-lab-um.github.io/R2spa/reference/fs_indiv.md)),
together with the three character-matrix attributes below. In addition,
three character matrices are added as attributes that can be used as
input to
[`tspa_mx_model()`](https://mmm-lab-um.github.io/R2spa/reference/tspa_mx_model.md):

- `ld`: cross-loading matrix

- `ev`: error variance-covariance matrix

- `int`: measurement intercepts
